# Rookery API Contract for `projects`

This document catalogs every Rookery JSON-RPC method, facility, manifest contribution type, collection feature, migration, host/client SDK surface, and cross-plugin extension/service integration used by `crow/plugins/projects`.

Each item is marked:

- **exists in Rookery now** — implemented in `rookery/` today (`rookery-proto`, `rookery-facilities`, `rookery-server`, `@rookery/client`, or `@rookery/sdk`).
- **needed (M2)** — arrives with the M2 plugin/extension-host/package runtime.
- **needed (M2b)** — arrives with the M2b datastore, spaces, documents, entities, and search runtime.
